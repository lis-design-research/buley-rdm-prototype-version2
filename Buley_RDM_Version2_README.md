# Buley RDM Prototype | Version 2

**Internal Group 4 development record | LIS 2024 | November 8, 2026**

## Why this repository exists

I created `buley-rdm-prototype-version2` to keep the modified HTML prototype separate from our original repository, `buley-rdm-libguide-prototype`.

**The original five-tab GitHub Pages prototype is our November 9 Team Prototype submission and the baseline for peer review.** A modified HTML file was uploaded to that original repository during development. I removed the additional file from the original repository and placed it in this separate repository so we can retain and review the proposed changes without altering the submission version.

This is a working draft for our team, **not the November 9 submission or an approved final design**. The separation lets us track what changed, what remains unfinished, and which revisions we may choose to incorporate after testing for the December 7 final design.

## What is still missing or not functional

- **Glossary:** The card does not contain definitions or open a glossary. Its placeholder link points to `re3data.org`.
- **Sample DMPs:** No sample plans are provided. Its placeholder link also points to `re3data.org`.
- **Feedback:** The card displays `suggestionbox@school.edu`, but its link points to `re3data.org`. It is not an email link or functioning feedback form, and it does not collect submissions.
- **Content and link review:** The modified wording, formatting, destinations, and proposed additions need review before any changes are adopted.

The modified file is still a **five-tab prototype**. The three new items are resource cards within **Tools & Resources**, not three additional navigation tabs.
